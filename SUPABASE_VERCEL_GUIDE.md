# Supabase + Vercel Integration Guide (NursingHub)

This guide provides a step-by-step method to integrate Supabase into your NursingHub deployment on Vercel for the Community features.

## 1. Supabase Project Setup
1. Create a free account at [supabase.com](https://supabase.com).
2. Create a new project named `nursinghub`.
3. Navigate to **SQL Editor** and run the following queries to create the necessary tables:

```sql
-- Create Posts Table
create table posts (
  id bigint generated by default as identity primary key,
  user_name text default 'Anonymous',
  content text not null,
  category text default 'General',
  likes int default 0,
  image_url text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Create Replies Table
create table replies (
  id bigint generated by default as identity primary key,
  post_id bigint references posts(id) on delete cascade,
  user_name text default 'Anonymous',
  content text not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
```

4. Navigate to **Storage**:
   - Create a new bucket named `community-images`.
   - Set the bucket to **Public**.

## 2. Storage Policies (Crucial for Image Uploads)
Navigate to **Authentication > Policies** and add these rules for the `community-images` bucket:
- **Select**: Allow all users to view.
- **Insert**: Allow all users to upload.

## 3. Vercel Deployment
1. Import your repository into Vercel.
2. During the "Configure Project" step, expand **Environment Variables**.
3. Add the following keys from your Supabase Dashboard (**Settings > API**):
   - `VITE_SUPABASE_URL`: Your Project URL.
   - `VITE_SUPABASE_ANON_KEY`: Your `anon` public key.
   - `VITE_DEEPSEEK_API_KEY`: (Optional) Your DeepSeek AI key for card generation.

## 4. SPA Routing Configuration
Ensure your `vercel.json` in the root directory looks like this to avoid 404 errors on refresh:

```json
{
  "rewrites": [
    { "source": "/(.*)", "destination": "/" }
  ]
}
```

## 5. Troubleshooting
- **CORS Errors**: Add your Vercel domain to **Settings > API > Allowed Origins** in Supabase.
- **Empty Feed**: If Supabase is not connected, the app will automatically fallback to `LocalStorage` for posts, ensuring it never appears broken.
